# Sanjana Gupta — Portfolio

Personal portfolio site built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy

Deploy this folder to [Vercel](https://vercel.com/new) and import the GitHub repo, or run:

```bash
npx vercel
```
